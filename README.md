# Спринт

Игра про бег на сто метров, в которой одна кнопка и всё решает ритм.

Ты не держишь стрелку вправо и не давишь на газ. Ты долбишь по экрану в такт, а ритм подстраивается под скорость: чем быстрее бежишь, тем чаще нужно бить. Собьёшься, и персонаж потеряет темп. Будешь слишком усердствовать, и тоже потеряет.

Что тут есть:

- **Пульс слышно.** Когда силы кончаются, темнеет в глазах, появляется рябь, сердце бухает в ушах, а потом начинается дыхание. Каждый забег эффект выпадает другой, где-то чуть-чуть, где-то прямо плохо.
- **Можно упасть в обморок.** Прибежал на последнем дыхании 200 метров и тут же полез на 150? Минуты отдыха не было, и на полпути ты просто ляжешь. То же самое, если бежишь слишком медленно.
- **Мировые рекорды надо заслужить.** Болт и Тервааг живут в таблице рекордов. Побить их можно только в четвёртой жизни, пройдя три перерождения.

## Как играть

1. Выбери дистанцию: 60, 100, 150 или 200 метров. Сначала открыта только 60, остальные открываются быстрыми забегами.
2. Жди выстрел. Ударишь раньше, получишь +0.2 секунды.
3. Бей по кнопке в такт зелёному кольцу. Метка должна стоять в зелёной зоне.
4. На заработанные монеты качай силу ног, скорость и выносливость.
5. Между забегами прыгай с места и крути скакалку: это тренирует ноги и даёт бонус к скорости, но тоже отнимает силы.

Как всё устроено, подробно: [www/game.js](www/game.js). Баланс сводится к трём формулам, остальное визуал.

## Запуск

Игра это обычная страница, но с одной оговоркой: three.js и шрифты в репозиторий не кладутся, их подтягивает скрипт.

```bash
npm install
npm run prepare-www
npx serve www
```

Открывай адрес из консоли на телефоне или в браузере.

## APK без Android Studio

В репозитории настроена сборка на GitHub. Каждый пуш в `main` собирает APK сам:

1. Открой вкладку **Actions**, выбери последний запуск «Сборка APK».
2. Внизу в разделе **Artifacts** скачай `sprint-apk`.
3. Распакуй, закинь `app-debug.apk` на телефон и установи. Android попросит разрешить установку из неизвестных источников.

## APK через Android Studio

```bash
npm install
npm run prepare-www
npx cap add android
npx cap sync android
npx cap open android
```

Дальше в Android Studio нажми Run или собери APK через **Build, Build Bundle(s) / APK(s), Build APK(s)**. Нужен JDK 17, студия подтянет остальное.

## Из чего сделано

Чистые HTML, CSS и JavaScript плюс three.js для трассы. Звук синтезируется на лету, кроме дыхания: оно записано живым человеком. Упаковка в приложение через Capacitor.
